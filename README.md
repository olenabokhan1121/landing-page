# Bang & Olufsen Landing Page

A responsive landing page inspired by Bang & Olufsen, a premium audio brand. The page presents featured products, product categories, information about the brand, and a contact form.

[Open the deployed Landing Page](https://olenabokhan1121.github.io/landing-page/)

## Technologies

- HTML5
- SCSS
- JavaScript
- Parcel
- Mate Academy Gulp Template

## Features

- Responsive layout for different screen sizes
- Navigation menu
- Recommended products section
- Product categories gallery
- About section
- Contact form

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/olenabokhan1121/landing-page.git
   ```

2. Navigate to the project folder:

   ```bash
   cd landing-page
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```

## Available Scripts

- `npm start` — starts the development server.
- `npm run lint` — checks the code for linting errors.
- `npm run build` — builds the project for production.
- `npm run deploy` — deploys the project to GitHub Pages.
